# ⚡SyntX – Multi-Language Code Compiler

SyntX is a backend-focused code compilation and execution platform built using **Java 21 and Spring Boot**.  
It supports executing **Java, Python, and JavaScript** code through a unified REST API, with a lightweight frontend for end-to-end demonstration.

---

## Features

- Multi-language code execution (Java, Python, JavaScript)
- RESTful APIs for submitting code and retrieving output
- OS-level execution using Java `ProcessBuilder`
- Strategy and Factory design patterns for extensible architecture
- Lightweight HTML/CSS/JavaScript frontend with line-numbered editor

---

## Tech Stack

- **Backend:** Java 21, Spring Boot, Maven  
- **Execution:** ProcessBuilder, Strategy & Factory Patterns  
- **Frontend:** HTML, CSS, JavaScript  

---

## Running the Project

### Prerequisites
- Java 21
- Maven
- Python 3.x
- Node.js

---

### Start the Application
```bash
mvn spring-boot:run
```
```bash
http://localhost:8080
```
